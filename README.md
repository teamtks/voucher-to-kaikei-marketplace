# voucher-to-kaikei-marketplace

証憑書類(領収書・請求書)から弥生会計・会計大将のインポートデータを作成する
スキルを、社内で共有するためのリポジトリです。

> **名前について**: このリポジトリ名は `voucher-to-kaikei-marketplace` ですが、
> `.claude-plugin/marketplace.json` に書かれた名前は `voucher-to-yayoi-marketplace`
> です(弥生会計のみ対応だった頃の名残)。Claude Desktopに登録したときのPC上の
> フォルダ名は、登録の仕方によってこのどちらにもなります。**フォルダ名を決め打ちに
> しないこと** — 過去に、この取り違えでスキルの自動更新が全く効かなくなったPCが
> ありました。

## 導入方法(各自のPCで1回だけ)

Claude Desktopアプリのチャット画面で `/plugin` と入力してもコマンドとして
認識されないため、**設定画面から操作**してください。

1. 左下(または歯車アイコン)から「設定」を開く
2. 左メニューの「Claude Code」→ さらにその中の「プラグイン」をクリック
3. 右上の「追加」→「マーケットプレイスを追加」
4. URL欄に `teamtks/voucher-to-kaikei-marketplace` と入力して「同期」
5. 一覧に表示された「証憑→弥生インポートデータ作成」の「+」ボタンをクリックしてインストール

これで、以降どのプロジェクトフォルダで作業していても、このスキルが自動的に
使えるようになります。

## 初回のみ必要な追加セットアップ(パソコンごとに1回)

このスキルは証憑画像の宛名を自動で黒塗りする処理のためにOCR(文字認識)の
プログラムを使います。これは**利用者が手作業で行う必要はありません** —
インストール後、Claude Codeのチャットで

```
voucher-to-yayoiスキルを使う準備をして
```

とお願いするだけで、Claude自身がフォルダの場所を特定し、必要なセットアップ
(このときだけインターネット接続が必要)を代わりに実行します。Pythonが
入っていないパソコンであっても、Claudeが自動でインストールします。

## 更新方法

各自のPCでは、アプリを立ち上げるたびにスキルが自動で最新化されるため、
**通常は何もする必要がありません。**

反映されない場合は、`tools/スキル強制更新.py`をデスクトップに置き、Claudeに
「デスクトップのスキル強制更新.pyを実行して」と頼んでください。GitHub上の最新版を
直接取りに行って突き合わせるため、**どんな配置のPCでも新旧を判定できます。**
それでも直らない場合は、再インストールの手順書に従ってください。

このファイルがまだPCに無い場合は、Claudeにこう頼めば取得できます(このリポジトリは
公開設定のため、認証は不要です)。

```
GitHubの teamtks/voucher-to-kaikei-marketplace にある
tools/スキル強制更新.py をデスクトップに保存してください。
```

「プラグイン」画面の「更新」ボタンは、**当てにしないでください。** このボタンは
GitHubではなく**PC内に保存されている複製とだけ**見比べています。その複製自体が
古くなっているPCでは、中身が古いままでも「更新済み」と判断されて灰色になり、
押せなくなります(実機で確認済み)。なお画面上のマーケットプレイス名は、上記の
とおりPCによって`voucher-to-kaikei-marketplace`と`voucher-to-yayoi-marketplace`
のどちらにもなりえます。

## 管理者向け: このマーケットプレイスに新しいスキルを追加する方法

今後、他の会計ソフト向けのスキルなどを追加する場合は、以下の手順で行います。

### 1. フォルダ構成

新しいスキルは `plugins/<スキル名>/` の下に、以下の形で追加します
(`voucher-to-yayoi` を参考にしてください)。

```
plugins/<スキル名>/
├── .claude-plugin/
│   └── plugin.json
└── skills/
    └── <スキル名>/
        └── SKILL.md (と必要なscripts等)
```

### 2. 【重要】ドットで始まるフォルダのアップロードに関する注意

`.claude-plugin` のような「.(ドット)」で始まるフォルダは、**GitHubのWeb画面で
ドラッグ&ドロップアップロードすると、ブラウザに隠しファイル扱いされて
アップロードから漏れてしまいます。** これは今回のセットアップ時に実際に
つまずいた点です。

回避策として、`.claude-plugin`フォルダの中身(`plugin.json`)は、
ドラッグ&ドロップではなく、GitHub画面の「Add file」→「Create new file」を使い、
ファイル名の欄に **フォルダ名を含めたパスをそのまま手入力** してください。

```
plugins/<スキル名>/.claude-plugin/plugin.json
```

このように入力すると、フォルダごと自動的に作成されます。

### 3. ルートの`marketplace.json`にも追加を忘れずに

リポジトリ直下の`.claude-plugin/marketplace.json`の`plugins`配列に、
新しいスキルの情報を1件追加してください(`voucher-to-yayoi`の記述を
コピーして書き換えるのが簡単です)。

### 4. 動作確認

自分のPCで「設定」→「Claude Code」→「プラグイン」を開き、このマーケットプレイス
(名前は`voucher-to-kaikei-marketplace`か`voucher-to-yayoi-marketplace`のどちらか)
の「…」→再同期を行い、新しいプラグインが一覧に表示され、インストールできることを
確認してから、社内に案内してください。

再同期が効かない場合は、`plugins/voucher-to-yayoi/skills/voucher-to-yayoi/scripts/doctor.py`
を実行すると、そのPCで何が起きているかを一覧で確認できます。
